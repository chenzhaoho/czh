网页通过本机 Python 后端控制正在运行的 ModelSim。发送侧暂存只负责等待 RTL ready；收件箱只采用实际读握手中的数据。消息头和 CRC32 由主机软件处理，FIFO 负责 32 位字的跨时钟传输。

原始记录和波形包含全部复位轮次；页面计数为当前轮次。重启会建立新会话，历史证据保留在各会话目录。

运行于单机的 RTL 功能仿真。仿真时间分批推进，100 MHz / 71.429 MHz 是模型内时钟频率。本页未连接 FPGA 板卡；数字仿真不验证模拟亚稳态。
